# Межа: кликабельный прототип

Прототип сервиса интерактивных генпланов для загородных поселков. Учебный проект: виджет генплана для покупателя и кабинет для собственника и менеджера на демо-данных, без сервера.

Онлайн: https://alexey-ryabkov.github.io/mezha-prototype/

Поселок, люди и компании вымышленные.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, деплой на GitHub Pages делает GitHub Actions при push в `master`.

Стек: Vite, React, TypeScript, Tailwind CSS, shadcn/ui, zustand, react-router (HashRouter).
